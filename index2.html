СТРУКТУРА БАЗЫ ДАННЫХ Таблица users (стандарт для всех билетов): - id INT AUTO_INCREMENT PRIMARY KEY - login VARCHAR(50) UNIQUE NOT NULL - password VARCHAR(255) NOT NULL - fio VARCHAR(100) NOT NULL - phone VARCHAR(20) NOT NULL - email VARCHAR(100) NOT NULL - created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP Таблица requests (базовая структура): - id INT AUTO_INCREMENT PRIMARY KEY - user_id INT NOT NULL - status VARCHAR(50) DEFAULT 'new' - created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP - FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE Таблица reviews (опционально): - id INT AUTO_INCREMENT PRIMARY KEY - user_id INT NOT NULL - request_id INT NOT NULL - rating INT CHECK (rating BETWEEN 1 AND 5) - comment TEXT - created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP - FOREIGN KEY (user_id) REFERENCES users(id) - FOREIGN KEY (request_id) REFERENCES requests(id) 2. SQL-ЗАПРОСЫ Выборка заявок с данными пользователя: SELECT r.*, u.fio, u.email, u.phone FROM requests r JOIN users u ON r.user_id = u.id ORDER BY r.created_at DESC Выборка заявок конкретного пользователя: SELECT * FROM requests WHERE user_id = ? ORDER BY created_at DESC Вставка новой заявки: INSERT INTO requests (user_id, поле1, поле2, status) VALUES (?, ?, ?, 'new') Обновление статуса: UPDATE requests SET status = ? WHERE id = ? Удаление заявки: DELETE FROM requests WHERE id = ? AND user_id = ? Статистика по статусам: SELECT status, COUNT(*) FROM requests GROUP BY status Пользователь оставил отзыв: UPDATE requests SET review = ? WHERE id = ? AND user_id = ? 3. ПРАВИЛА ВАЛИДАЦИИ ПОЛЕЙ Логин: латиница и цифры, минимум 6 символов Код: preg_match('/^[a-zA-Z0-9]{6,}$/', $login) Пароль: минимум 8 символов Код: strlen($password) >= 8 ФИО: только буквы (русские или английские) и пробелы Код: preg_match('/^[а-яА-ЯёЁa-zA-Z ]+$/u', $fio) Телефон: формат 8(XXX)XXX-XX-XX Код: preg_match('/^8\(\d{3}\)\d{3}-\d{2}-\d{2}$/', $phone) Email: стандартный формат Код: filter_var($email, FILTER_VALIDATE_EMAIL) Дата: формат ДД.ММ.ГГГГ Код: DateTime::createFromFormat('d.m.Y', $date) && $d->format('d.m.Y') === $date 4.
